# Клодитет · Кабінет студента

Прототип вебзастосунку (темна тема в стилі iOS) «Кабінет студента» університету **Клодитет**. Чистий HTML5 / CSS / JavaScript без збірки та бекенду — готовий до публікації на GitHub Pages.

## Розділи

- **Головна** — привітання, пари на сьогодні, найближчі дедлайни, успішність, оголошення
- **Розклад** — по днях, парний/непарний тиждень, підсвітка поточної пари, експорт у `.ics`
- **Дисципліни** — картки курсів, програма, відвідуваність, поточний бал
- **Завдання** — фільтри за статусом, здача роботи (drag-and-drop файлу), відкликання, оцінки та відгуки
- **Залікова книжка** — усі семестри, ECTS, динаміка середнього бала
- **Фінанси** — стипендія, борг за гуртожиток, імітація онлайн-оплати, історія операцій
- **Бібліотека** — книги на руках, продовження, повернення, пошук по каталогу та бронювання
- **Повідомлення** — чати з куратором, деканатом, викладачами, автовідповіді
- **Заявки та довідки** — подання заявок, статуси, таймлайн, завантаження PDF
- **Фортуна** — рулетка з розіграшем квитків на Halloween Disco: 3 спроби на день, зважені призи, конфеті, іменні квитки з QR
- **Профіль** — дані студента, електронний студентський з QR, налаштування, безпека

Усі дії зберігаються у `localStorage`. Кнопка «Скинути демо-дані» у профілі повертає початковий стан.

## Публікація на GitHub Pages

Деплой повністю автоматичний через GitHub Actions (`.github/workflows/deploy.yml`): кожен пуш у `main` збирає та публікує сайт.

Одноразове налаштування: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Після першого пушу сайт буде доступний за адресою `https://<owner>.github.io/student-cab/`.

## Локальний запуск

Жодних залежностей та збірки: просто відкрийте `index.html` у браузері.
